# 2026-10-04

## GUI 两项优化（提示配色 + 原文模式可复制）

**一、语义色板 `gui/src/palette.rs`（新增）**
- 起因：旧代码直接写 `Color32::RED/GREEN/YELLOW/GRAY`。实测在 egui 浅色面板 `#F8F8F8` 上对比度
  只有 3.76 / 1.29 / **1.01** / 3.72，全部低于 WCAG AA 的 4.5:1（黄色基本看不见）。
- 做法：`Tone{Danger,Success,Warning,Muted}` + `color(ui)`（按 `ctx.theme()` 自动切浅/深两套）。
  浅色：`#C62828` / `#166534` / `#92400E` / `#4B5563`；深色：`#FF7B72` / `#56D364` / `#D29922` / `#9CA3AF`。
- 色弱可辨识：每个色调配专属图标（✗ ✓ ⚠ ○），且要求列表的状态图标由「●/●」改成「⛔/✓」；
  另加单测守住"图标互不相同 + 危险/成功明度比 > 1.3"。
- `App` 新增 `msg_tone: Tone` + `set_msg(tone, text)`：失败红 / 成功绿 / 提示琥珀（默认=旧行为），
  ~30 处 `message = Some(..)` 全部改走它；底部提示带图标渲染。
- 单测：`palette::tests` 三条（AA 对比度、旧纯色确实不达标、图标与明度），浅底含 `#FFF/#F8F8F8/#F0F0F0`，
  深底含纯黑/`#1B1B1B`/`#252525`。
- ⚠ egui 0.36 的 `Visuals` **没有** `dark` 字段，主题要问 `ctx.theme()`。

**二、原文（Markdown 源码）模式可选中 / 可复制**
- 起因：`TextEdit::multiline(text).interactive(false)` → sense 退化成 `Sense::hover()`，
  点不中、拿不到焦点、收不到 `Event::Copy`、也挂不上右键菜单。
- 做法：`read_only_text(ui, id_salt, size, font, text)`——传 `let mut buf: &str = text;` 进去，
  借 egui 给 `&str` 的 TextBuffer（`is_mutable()==false`、写入全空实现）实现"交互全开但改不动"；
  挂 `context_menu`：复制选中 / 全选 / 复制全文（"复制选中"经 `selected_text()` 读 `TextEditState`）；
  `add_raw_text` 顶部加「复制全文」按钮 + "可选中文字；Ctrl+C 或右键菜单复制"提示。
  评论正文面板同样的老写法一并修掉（共用 `read_only_text`）。
- 新增 4 条单测：`&str` 不可变 buffer（机制守卫）、只读框参与指针交互（焦点/拖拽态）、
  选中内容两个出口（右键取值 + Ctrl+C 产生 CopyText）、一键复制全文按钮。
- 离屏测试踩坑：`run_ui` 里 galley 几何退化（`rect` 0×0），`cursor_from_pos` 恒返回第 0 字符、
  `clamp_cursor` 会把 0..9 夹成 0..2 —— 用**可编辑的 `String` buffer 做对照实验**确认是环境限制，
  于是鼠标框选只断言"能进拖拽态"，选区内容改在状态层面验。

**验证**：`cargo test -p req-guard-gui` 30 通过；`cargo test --workspace` 219 通过（core 173/gui 30/tui 16）；
`cargo fmt -p req-guard-gui -- --check` 与 `cargo clippy -p req-guard-gui --all-targets -- -D warnings` 零告警。
真机截图（macOS/浅色主题）确认：绿 `#166534` 已解锁、红 `#C62828` 未解锁 + ⛔、琥珀 `#92440E` 提示、
原文视图含「复制全文」按钮且 Markdown 渲染预览无变化。截图用临时 `with_always_on_top()` + 改初始
state（render_md/selected/message）后已全部回滚（已核对 `selected: 0`/`render_md: true`/`message: None`）。

**顺手整理**：`.workbuddy/memory/MEMORY.md` 从 16KB 归拢成规则清单（历史细节留各日期日志）。
