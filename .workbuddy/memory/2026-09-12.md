### 关键结论（可复用）
- **ratatui 0.30.2 的 `rust-version = 1.88.0`（edition 2024）** → sql-guard 的 `rust:1.80` 镜像**不能**用于含 TUI 的构建；
  用 `cargo metadata` 扫 CLI+TUI 全依赖链确认最高 MSRV 恰为 1.88.0（time-core/time/ratatui-widgets 同）。
- req-guard 的 CLI+TUI 依赖链**零 C 代码**（无 `cc`/`psm`/`stacker`）→ **不需要** sql-guard 那套「Zig 当交叉 C 编译器」的
  `make_zig_cc` 封装脚本；Zig 仅用于 macOS 的 cargo-zigbuild。
- **windows-gnu 仍必须装 mingw**（`gcc-mingw-w64-x86-64`）：实测把 linker 换成 `rust-lld` 会失败
  （`lld: error: unable to find library -lkernel32`），且默认真实链接还依赖 `-lgcc/-lmingw32/-lmingwex`。
- **GUI（eframe/wgpu/rfd）无法从 Linux 交叉编译**（Linux 侧要 X11/Wayland/GTK 系统库）→ 智能原生执行机构建，
  故本次 release 矩阵只覆盖 CLI / CLI+TUI。
