## 顺带修掉一个 Windows 专属的测试假红（**不在本次需求范围内，已向用户说明**）

首次 `cargo test --workspace` 在 `core` 挂 1 条：
`requirement::tests::archive_due_按判龄归档并按年分层`（`core/src/requirement.rs`）——
断言写成 `by_id["REQ-001"].to_string_lossy().ends_with("archive/misc/REQ-001.md")`，
而 `Path` 分隔符平台相关：Linux 是 `/`（CI 永远绿），Windows 是 `\` → 必红。

**根因**：测试把"平台无关的路径比较"写成了"平台相关的字符串后缀比较"。
**修复**：断言前统一 `.replace('\\', "/")` 归一（与生产代码 `gate::is_requirement_doc` 的路径处理同一约定）。
不是版本号改动引起的（`git status` 可证 requirement.rs 此前未被本次改动触碰，该断言来自归档功能提交 `014648e`）。
