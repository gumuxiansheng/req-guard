### egui 0.36 与 0.33 的 API 差异（重要，其他 egui 项目升级时会全踩）
1. **`eframe::App` 拆成两个回调**：`update(ctx, frame)` 没了 →
   `logic(&mut self, ctx, frame)`（无 UI 逻辑/重绘调度）+ `ui(&mut self, ui: &mut egui::Ui, frame)`（渲染，给的是根 Ui 而非 Context）。
2. **面板体系重构**：`TopBottomPanel` / `SidePanel` 没了 → 统一 `egui::Panel::{top,bottom,left,right}`，
   `show` 接收 `&mut Ui`（不是 &Context）；`CentralPanel` 保留但用 `default_margins()`/`no_frame()`，无 `default()`。
3. `CollapsingHeader::open(Option<bool>)` 按值传递（不再 `Option<&mut bool>`）。
4. 核对方法：直接读 registry 源码
   `~/.cargo/registry/src/mirrors.ustc.edu.cn-*/eframe-0.36.2/src/epi.rs`（App trait）、
   `egui-0.36.2/src/containers/panel.rs`（Panel）——比查 docs.rs 快且准。
