## 执行修复：P0/P1 + 测试 + CI（同日晚）

按"先 P0 → 测试 → 工程化"顺序全部落地，逐项真机复验。

### 修复内容
- **P0-1 命名统一**：`ai-gate-*` → `req-guard-*`。新增常量 `gate::HOOK_SH_REL` / `HOOK_PS1_REL`
  作为唯一真相，install / check / PRE_COMMIT_BLOCK / 片段引用全部对齐；回归测试断言片段引用的
  路径 == 代码生成路径。
- **P0-2 ps1 BOM**：新增 `gate::ps1_with_bom()`（写盘前拼 `\u{feff}`）与 `gate::has_utf8_bom()`；
  `check()` 发现旧脚本缺 BOM 时给出可操作告警。实测：加 BOM 前 `check` 恒 exit 1，加后正常。
- **P1 评论文件污染**：`requirement::COMMENTS_SUFFIX` 成为命名约定唯一出处；
  `list()` 与 sh/ps1 脚本遍历均排除 `*.comments.md`；顺带修 `list` 标题重复编号。
- **P1 reply**：`GATE:COMMENT` 增 `reply=C00N` 字段；`comment::add` 入参改为
  `NewComment` 结构体（顺带满足 clippy 参数数限制），`author=ai` 无 `--reply` 直接拒绝、
  回复目标必须存在；`is_ai()` 抽为公共判定。
- **P1 审计**：新增 `gate::audit(root, entry)`；`comment::add/resolve` 写
  `COMMENT-ADD` / `COMMENT-RESOLVE`，`bypass` 改为复用它。
- **P1 strict_order**：新增 `gate::strict_order(root)` 逐行解析 yaml（跳过注释，缺省 true），
  `main` 用它替代硬编码 `true`；实测改 false 后跳步审核可通过。
- **P1 gitignore**：`append_gitignore()` 幂等追加 `.gates/.bypass` 与 `.gates/audit/*.log`。
- **install 幂等语义收紧**：声明类文件（yaml/README）存在则保留不覆盖，脚本仍随版本覆盖。
