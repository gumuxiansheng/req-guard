# REQ-009 判决性实验清单 —— 「这些判据必须有人守着」的书面合同
#
# 格式：<文件>\t<锚点原文>\t<追加文本>\t<测试过滤串>\t<理由>
#   - 五个字段以**单个 TAB** 分隔，无转义、无多行。某段里含 TAB 即格式非法。
#   - 锚点必须能在目标文件里**唯一**命中；0 处 = 清单腐化，≥2 处 = 歧义。
#   - 「追加文本」是**追加到锚点所在行行尾**的内容，不是整行替换 ——
#     行数不变是刻意的：`mask_fenced` 的调用方依赖行号。
#   - 理由**必填**：它是这份清单里最容易随时间丢失的东西。
#
# 跑法：bash scripts/verify_tests_have_teeth.sh [--only <行号|理由关键字>]
#
# 收录判据的口径（N2）：只收「失效方向最坏」的 —— 即失效时门禁表现为
# **看起来在拦、实际没拦**。清单只能覆盖已经想到的失效方向；
# 「没想到的」靠每次复盘追加，不是自动化能解决的。
